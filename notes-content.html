Study Notes

Web Development

HTML is used to create the structure of a webpage.

CSS is used to style and design webpages.

JavaScript is used to add functionality and interaction.

Database Management System

DBMS is software used to store and manage data.

SQL is used to create, read, update and delete data.

Examples: MySQL, MongoDB, Oracle.

Operating System

An operating system manages computer hardware and software.

It manages processes, memory and files.

Examples: Windows, Linux and macOS.
