# Smart Campus Management System

## About the Project

Smart Campus Management System is a frontend web development project designed to help students access their academic information through a simple and user-friendly interface.

## Features

- Student Registration and Login
- Student Dashboard
- Student Profile Management
- Change Password
- Attendance Tracking
- Assignment Management
- Notes Section
- Interactive Timetable
- Results and Grades
- Notice Board
- Responsive Design for Mobile Devices

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage

## Project Type

Frontend Web Development Project

## How to Run

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open frontend/index.html with Live Server.
4. Register a student account and log in to explore the features.

## Purpose

This project was developed for learning and demonstrating frontend web development skills using HTML, CSS, and JavaScript.
